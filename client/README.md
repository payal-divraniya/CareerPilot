# CareerPilot Frontend

React + Vite + Tailwind CSS frontend for CareerPilot Job Application Tracker. This frontend has no AI functionality.

## Commands
```bash
npm install
npm run dev
npm run lint
npm run build
```

Set `VITE_API_URL` in `.env` to the backend API base URL ending in `/api`. Local default: `http://localhost:5000/api`. Copy `.env.example` as needed.
